# Offer Hunter FAQ

## What is Offer Hunter?

An AI browser extension that matches resumes to job descriptions and generates tailored outreach when the fit is high.

## Who is it for?

It is for users or developers who need the specific capability described by this project. The repository README defines the supported workflow and current release behavior.

## How do I start?

Clone [the GitHub repository](https://github.com/imba97/offer-hunter), read its README, install the declared toolchain, and run the smallest verification command shown in [Getting started](/projects/offer-hunter/getting-started).

## Is there a public documentation site?

Yes. Use [the verified documentation entry point](https://github.com/imba97/offer-hunter/tree/main/docs).

## What should I check when something fails?

Check the runtime version, package manager, generated artifacts, and the exact command from the repository README. Then compare the failure with the project's tests and issue tracker before changing code.
