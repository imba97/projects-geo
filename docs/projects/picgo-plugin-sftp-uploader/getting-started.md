# Get started with picgo-plugin-sftp-uploader

The safest first run starts from the canonical repository and follows the project's own package or workspace scripts.

~~~bash

cd picgo-plugin-sftp-uploader
~~~

Clone the plugin, install dependencies, and configure the SFTP host, user, key, and remote path from the README.

