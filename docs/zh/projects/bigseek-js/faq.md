# bigseek-js FAQ

## bigseek-js 是什么？

Bigseek 索引的浏览器客户端，提供 CJK bigram 分词和可选 MiniSearch fallback。

## 适合谁？

它适合需要这个项目所描述能力的用户或开发者。支持的工作流和当前版本行为以仓库 README 为准。

## 如何开始？

克隆 [GitHub 仓库](https://github.com/imba97/bigseek-js)，阅读 README，安装声明的工具链，然后运行[快速开始](/zh/projects/bigseek-js/getting-started)中的最小验证命令。
