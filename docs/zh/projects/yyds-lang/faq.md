# yyds-lang FAQ

## yyds-lang 是什么？

YYDS 语言 monorepo，包含 grammar、AST、lexer、parser、semantic、language service 和编辑器工具链。

## 适合谁？

它适合需要这个项目所描述能力的用户或开发者。支持的工作流和当前版本行为以仓库 README 为准。

## 如何开始？

克隆 [GitHub 仓库](https://github.com/yyds-lang/yyds)，阅读 README，安装声明的工具链，然后运行[快速开始](/zh/projects/yyds-lang/getting-started)中的最小验证命令。

## 有公开文档站吗？

有，使用[已确认的文档入口](https://github.com/yyds-lang/yyds/tree/main/docs)。

## 出错时先检查什么？

先检查运行时版本、包管理器、生成产物，以及 README 中的准确命令，再对照测试和 issue 信息定位问题。

## 事实来源在哪里？

[GitHub 仓库](https://github.com/yyds-lang/yyds)
