# Offer Hunter FAQ

## Offer Hunter 是什么？

AI 浏览器扩展，用于分析简历与岗位 JD 的匹配度，并在匹配度高时生成定制打招呼语。

## 适合谁？

它适合需要这个项目所描述能力的用户或开发者。支持的工作流和当前版本行为以仓库 README 为准。

## 如何开始？

克隆 [GitHub 仓库](https://github.com/imba97/offer-hunter)，阅读 README，安装声明的工具链，然后运行[快速开始](/zh/projects/offer-hunter/getting-started)中的最小验证命令。

## 有公开文档站吗？

有，使用[已确认的文档入口](https://github.com/imba97/offer-hunter/tree/main/docs)。

## 出错时先检查什么？

先检查运行时版本、包管理器、生成产物，以及 README 中的准确命令，再对照测试和 issue 信息定位问题。
