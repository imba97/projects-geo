# ontograph-cli FAQ

## ontograph-cli 是什么？

实体关系知识图谱 CLI，用于添加实体、建立关系并查询图谱。

## 适合谁？

它适合需要这个项目所描述能力的用户或开发者。支持的工作流和当前版本行为以仓库 README 为准。

## 如何开始？

克隆 [GitHub 仓库](https://github.com/imba97/ontograph-cli)，阅读 README，安装声明的工具链，然后运行[快速开始](/zh/projects/ontograph-cli/getting-started)中的最小验证命令。

## 有公开文档站吗？

当前项目清单中没有确认到已部署的文档域名，应以仓库 README 和源文档为准。

## 出错时先检查什么？

先检查运行时版本、包管理器、生成产物，以及 README 中的准确命令，再对照测试和 issue 信息定位问题。
